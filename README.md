# Step Up Dance Studio — website

This is the public STEP UP website at stepupdancegr.com. It is a static HTML,
CSS, and JavaScript repository on GitHub, deployed to Netlify from `main`.
There is no Laravel application in this website.

Step Up Connect (`app.stepupdancegr.com`) is a separate Lovable application
with its own package catalog and student subscriptions. Changes to the public
pricing pages do not update the Lovable app automatically.

The public pricing pages (`/el/pricing/` and `/pricing/`) render data from
`content/pricing-el.json` and `content/pricing-en.json` respectively.
